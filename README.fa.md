> **وضعیت پروژه:** نسخه ۱٫۰ بتا. همیشه از عکس‌های مهم یک نسخه پشتیبان مستقل داشته باشید. برنامه محتوای عکس را ویرایش نمی‌کند، اما حالت «انتقال» پس از تأیید کاربر فایل را جابه‌جا می‌کند.

## قابلیت‌ها

- اسکن بازگشتی پوشه‌ها و ثبت در کاتالوگ SQLite
- نمایش شبکه‌ای بندانگشتی و پیش‌نمایش بزرگ
- رابط فارسی راست‌به‌چپ و رابط انگلیسی
- افزودن عکس به روش **ثبت در محل**، **کپی** یا **انتقال**
- مرتب‌سازی آرشیو بر اساس `سال/سال-ماه-روز`
- تشخیص محتوای تکراری با SHA-256، مستقل از نام فایل
- تگ‌گذاری هم‌زمان چند عکس و حذف تگ
- جست‌وجوی نام، مسیر و یادداشت و فیلتر تگ
- امتیاز صفر تا پنج ستاره
- خواندن تاریخ EXIF، دوربین، لنز، ابعاد و حجم
- تشخیص فایل‌های گم‌شده و پشتیبان‌گیری از کاتالوگ
- پوسته روشن و تاریک
- فعالیت کاملاً آفلاین؛ بدون حساب، فضای ابری یا تله‌متری
- فایل نصب و نسخه پرتابل Windows x64 از بخش Releases

## نصب در ویندوز

از بخش **Releases** مخزن یکی از این فایل‌ها را دریافت کنید:

- `PhotoManager-Setup-1.0.0-x64.exe` برای نصب معمولی؛
- فایل `windows-x64.zip` برای نسخه پرتابل.

چون برنامه فعلاً گواهی تجاری امضای دیجیتال ندارد، ممکن است Windows SmartScreen هشدار بدهد. مقدار SHA-256 فایل را با checksum همان Release مقایسه کنید و فقط در صورت یکسان‌بودن، از مسیر *More info → Run anyway* ادامه دهید.

## اجرای کد منبع

Python 3.11 یا جدیدتر لازم است:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m photomanager
```

## شروع سریع

1. با **افزودن پوشه** عکس‌ها را بدون جابه‌جایی ثبت کنید.
2. با **ورود عکس‌ها** یک پوشه را ثبت، کپی یا منتقل کنید.
3. یک یا چند عکس را انتخاب و تگ‌ها را با ویرگول جدا کنید.
4. بر اساس نام، مسیر، یادداشت، تگ یا حداقل امتیاز جست‌وجو کنید.
5. مرتباً از گزینه **پشتیبان‌گیری از کاتالوگ** استفاده کنید. این گزینه از اطلاعات برنامه پشتیبان می‌گیرد، نه از فایل عکس‌ها.

### ایمنی Import

| روش | فایل مبدأ | آرشیو |
|---|---|---|
| ثبت در محل | بدون تغییر باقی می‌ماند | کپی ساخته نمی‌شود |
| کپی | بدون تغییر باقی می‌ماند | نسخه مرتب‌شده ساخته می‌شود |
| انتقال | از مبدأ منتقل می‌شود | نسخه مرتب‌شده ساخته می‌شود |

فایل تکراری با هش SHA-256 رد می‌شود. فایل موجود در مقصد بازنویسی نمی‌شود و در صورت تشابه نام، شماره به نام جدید افزوده خواهد شد. تگ، امتیاز و یادداشت داخل کاتالوگ هستند و فایل اصلی را تغییر نمی‌دهند.

## فرمت‌ها

JPG، JPEG، PNG، WebP، BMP، GIF و TIFF به‌صورت پیش‌فرض پشتیبانی می‌شوند. فایل‌های HEIC و RAW دوربین نیز قابل ثبت هستند، ولی نمایش و EXIF آن‌ها به codec ویندوز و نوع دوربین بستگی دارد.

## محل اطلاعات برنامه

کاتالوگ و کش تصاویر معمولاً در مسیر کاربری زیر قرار می‌گیرند:

```text
%LOCALAPPDATA%\Mooli-web\Photo Manager\
```

حذف برنامه، عکس‌های اصلی را حذف نمی‌کند. پیش از پاک‌کردن اطلاعات برنامه از کاتالوگ خروجی پشتیبان بگیرید.

## ساخت فایل EXE

```powershell
pip install -r requirements-dev.txt
pytest
pyinstaller --noconfirm PhotoManager.spec
iscc installer.iss
```

فایل اجرایی داخل `dist` و نصب‌کننده داخل `installer-output` ساخته می‌شود. با Push کردن تگی مثل `v1.0.0`، GitHub Actions خروجی ویندوز را می‌سازد و به Release متصل می‌کند.

## حریم خصوصی و محدودیت‌ها

برنامه هیچ درخواست اینترنتی ندارد. تشخیص چهره، تگ‌گذاری هوشمند، نقشه، فضای ابری و ویرایش عکس در نسخه ۱٫۰ نیستند. آلبوم‌ها و فیلترهای ترکیبی پیشرفته در نقشه راه قرار دارند.

## مشارکت و مجوز

راهنمای مشارکت در [CONTRIBUTING.md](CONTRIBUTING.md) و نقشه راه در [ROADMAP.md](ROADMAP.md) است. این پروژه با مجوز MIT منتشر می‌شود. تصاویر یا کاتالوگ شخصی را داخل Issue قرار ندهید.
