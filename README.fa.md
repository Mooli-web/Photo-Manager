> **نسخه ۲ فعلاً پیش‌انتشار است.** نسخه Python همچنان در Release قبلی وجود دارد، اما برای پوشه‌های بزرگ توصیه نمی‌شود. همیشه از عکس‌های مهم یک نسخه پشتیبان مستقل داشته باشید.

## چرا نسخه ۲؟

در پروتوتایپ قبلی، اسکن دیسک، هش کامل، خواندن EXIF، نوشتن دیتابیس و ساخت Thumbnail روی Thread رابط انجام می‌شد. در پوشه بزرگ، ویندوز برنامه را بدون پاسخ تشخیص می‌داد. نسخه ۲ این معماری را به‌طور کامل جایگزین می‌کند.

## معماری جدید

- **C#، ‎.NET 10 LTS، WPF و MVVM**
- جداسازی Domain، Application، Infrastructure و رابط
- کانال‌های Async با ظرفیت محدود و ۲ تا ۶ Worker
- هیچ اسکن، هش یا EXIF روی Thread رابط انجام نمی‌شود
- هش سریع ابتدا/انتهای فایل؛ SHA-256 کامل فقط برای موارد مشکوک به تکراری
- SQLite در حالت WAL و ثبت دسته‌ای هر ۱۰۰ رکورد
- بارگذاری صفحه‌ای ۲۰۰ رکورد و فهرست مجازی WPF
- Thumbnail تنبل با حداکثر چهار Decoder هم‌زمان
- تأخیر کنترل‌شده جست‌وجو، پیشرفت واقعی و امکان توقف
- جداسازی خطای هر فایل و ثبت گزارش خطا
- اسکن کاتالوگ هیچ تغییری در فایل عکس ایجاد نمی‌کند

جزئیات در [ARCHITECTURE.md](ARCHITECTURE.md) آمده است.

## بدون نصب وابستگی

خروجی‌ها **Self-contained و تک‌فایلی** هستند. کاربر لازم نیست .NET، Python، SQLite یا کتابخانه دیگری نصب کند؛ تمام Runtime و کتابخانه‌ها در خروجی قرار می‌گیرند.

| دستگاه | فایل مناسب |
|---|---|
| بیشتر کامپیوترهای Windows 10/11 | `PhotoManager-Setup-2.0.0-win-x64.exe` |
| نسخه پرتابل x64 | `PhotoManager-2.0.0-win-x64-portable.zip` |
| Windows on ARM | `PhotoManager-2.0.0-win-arm64-portable.zip` |

WPF فقط روی Windows اجرا می‌شود. این خروجی‌ها روی macOS یا Linux اجرا نمی‌شوند. منظور از «بدون وابستگی» این است که Runtime جداگانه لازم نیست، نه اینکه یک فایل روی همه سیستم‌عامل‌ها و پردازنده‌ها اجرا شود.

## قابلیت‌های فعلی نسخه ۲

- اسکن بازگشتی پاسخ‌گو با شمارنده زنده، پیشرفت و توقف
- کاتالوگ SQLite مقاوم با شناسه مسیر کامل
- JPG، PNG، WebP، BMP، GIF و TIFF و ثبت پسوندهای رایج HEIC/RAW
- خواندن تاریخ، ابعاد، دوربین و لنز در صورت قابل‌خواندن‌بودن Metadata
- جست‌وجوی نام، مسیر و یادداشت و فیلتر تگ
- تگ گروهی، یادداشت و امتیاز صفر تا پنج
- بررسی فایل گم‌شده و پشتیبان‌گیری سازگار دیتابیس
- رابط فارسی راست‌به‌چپ و انگلیسی
- نصب‌کننده مستقل x64 و نسخه پرتابل x64 و ARM64

در مرحله مهاجرت، Copy و Move عمداً غیرفعال شده‌اند. ابتدا کاتالوگ غیرمخرب پایدار می‌شود. Import پس از اضافه‌شدن Journal، بررسی سلامت کپی و بازیابی عملیات نیمه‌کاره برمی‌گردد.

## ساخت و تست برای توسعه‌دهنده

فقط توسعه‌دهنده به SDK نسخه ۱۰ نیاز دارد:

```powershell
dotnet test tests/PhotoManager.Tests/PhotoManager.Tests.csproj -c Release
./scripts/publish.ps1
```

برای نصب‌کننده، Inno Setup 6 فقط روی کامپیوتر سازنده لازم است؛ کاربر نهایی به هیچ‌کدام نیاز ندارد.

## انتشار نسخه آزمایشی

```bash
git tag v2.0.0-beta.1
git push origin v2.0.0-beta.1
```

GitHub Actions تست‌ها را اجرا می‌کند، خروجی‌های مستقل x64 و ARM64 و نصب‌کننده x64 را می‌سازد، checksum تولید می‌کند و یک Pre-release می‌سازد.

## حریم خصوصی و اطلاعات

برنامه آفلاین است و حساب، تله‌متری یا API ابری ندارد. اطلاعات نسخه ۲ در مسیر زیر ذخیره می‌شوند:

```text
%LOCALAPPDATA%\Mooli-web\PhotoManager\
```

کاتالوگ نسخه ۲ از نسخه ۱ جداست. اسکن فقط عکس‌ها را می‌خواند و تگ، امتیاز و یادداشت داخل SQLite باقی می‌مانند.
